# Historias de usuario — Rehab Elite

Catálogo de historias de usuario del sistema de gestión clínica y seguimiento terapéutico. Cada historia tiene un issue en GitHub (plantilla **Historia de usuario**) y se implementa en una rama `feature/HU-XX-descripcion` desde `develop`.

> **Pendiente:** completar con las historias del backlog del proyecto (ver sección [Historias](#historias)).

## Roles

| Rol | Descripción |
|---|---|
| Administrador | Gestiona usuarios y la configuración del sistema |
| Fisioterapeuta | Registra pacientes, historial clínico, tratamientos, sesiones y valida los resúmenes generados con IA |
| Paciente | Consulta en modo de solo lectura su propio tratamiento desde el portal |
| Dirección operativa | Consulta reportes e indicadores de la clínica |

## Formato

Cada historia sigue el formato:

- **Como** [rol] **quiero** [funcionalidad] **para** [beneficio].
- Criterios de aceptación en formato **Dado / Cuando / Entonces**, numerados CA1, CA2, …
